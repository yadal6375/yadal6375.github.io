# むすぶ

図形をタップして回し、線の端をすべてつなぐパズル。ブラウザだけで動きます。

## 遊びかた

- 図形をタップ（クリック）すると時計回りに90°回ります。右クリックで逆回り
- 線の端が1本も余らない状態にすれば正解
- つながった塊が大きくなるほど、線の色が濃くなり、鳴る音が高くなります
- 問題は毎回その場で生成されるので、同じ盤面は出ません

## 中身

外部ライブラリなし。HTML1ファイルに全部入っています。

- **問題生成** — 盤面全体を通る木をランダムに作り、そこに輪を少し足す。どのマスにも必ず線が来て、必ず解ける
- **色** — つながっている塊の大きさを union-find で求め、グレー → ターコイズ → 藍へ配色
- **音** — Web Audio でその場で合成（音声ファイルなし）。塊の大きさをヨナ抜き五音音階に対応させている
- **答えを見る** — 押した瞬間の配置から、中心を起点に波が広がるように正解へ回っていく。各マスは最短の回転角を選ぶので、すでに合っている駒は動かない
