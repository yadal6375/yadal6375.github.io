# あそびば

ちいさなブラウザゲームの置き場。

- **[むすぶ](https://yadal6375.github.io/musubu/)** — 図形を回して線の端をすべてつなぐパズル
- **[くみたてる](https://yadal6375.github.io/kumitateru/)** — 部品を並べて漢字を組み立てるパズル
- **[たぐる](https://yadal6375.github.io/taguru/)** — Wikipedia の本文の最初のリンクをたどりつづける

## くみたてる

部品を台にドラッグして並べ、漢字を組み立てます。木と木で林、林と木で森。
組み上げた字は、次からその人の部品になります。

- 常用漢字 **2136字**。うち **1996字** が組み立てられます（残る140字は部品そのもので、分解できません）
- 部品は **664種**。素の部品（作れないもの）は291種で、1字つくるごとに1つずつ増えます
- 判定は**部品の集合で候補を絞り、置き方のずれで決めます**。手を止めて1秒たつと走ります
- 進行は localStorage に保存されます
- はじめて開いた人には、木と木で林を組む**実演が一度だけ流れます**（フッターの「使い方」で見返せます）。
  本物の判定を通して見せますが、終わると持ちものを実演前に戻すので、はじめての1字は遊ぶ人のものです

連想や語呂合わせではなく、KanjiVG に記録された**実際の字形構造**をそのまま遊びにしています。
だから組み上がるたびに「へえ」が残ります。

### データの作りかた

```
git clone --depth 1 https://github.com/KanjiVG/kanjivg.git
curl -sSLo data/joyo.tsv https://raw.githubusercontent.com/hiroshi-manabe/Joyo-Kanji-List/master/joyo.tsv

python3 tools/extract.py --verify                              # 外接矩形の検算
python3 tools/extract.py --survey                              # 部品の粒度を比べる
python3 tools/extract.py --min-strokes 2 --out data/kumitateru.json
node tools/judge-test.mjs 13 0.15                              # 判定の検証
```

`kanjivg/`（90MB）と `data/joyo.tsv` はこのリポジトリには含みません。上のコマンドで取得してください。

### 判定の設定

`kumitateru/index.html` の先頭 `CFG` で調整できます。

| 項目 | 値 | 意味 |
|---|---|---|
| `OK` | 13 | この誤差以下ならその字と認める |
| `WS` | 0.15 | 大きさのずれの重み。位置より軽く見る |
| `SETTLE` | 1000 | 手が止まってから判定するまで（ミリ秒） |
| `START` | 10 | 最初に持っている素の部品の数 |
| `PER_FIND` | 1 | 1字つくるごとに増える素の部品の数 |

現在の設定での実測（全1996字）:

| 状況 | 結果 |
|---|---|
| 正解どおりに置く | 1996/1996 通る（最大誤差 8.8） |
| ±8 ずらす | 97.3% 通る |
| ±18 ずらす | 14.7% 通る |
| でたらめに置く | 0.20% しか通らない |
| 部品が同じでぶつかる10組 | 取り違え 0 |

### 分解の決めごと

KanjiVG の記録をそのまま使いますが、2つだけ判断を入れています。

- **常用漢字に当たったら分解を止める。** 最後まで割ると 森＝木木木 になり、
  「組み上げた字が次の部品になる」という遊びの背骨が消えます。止めれば 森＝木＋林 です
- **どの部品にも属さない画は、3本までならその画自体を1部品として数える**（`MAX_ORPHANS`）。
  0本にすると観・楽・電のような字がまるごと作れなくなり、
  制限を外すと鬯が筆画に崩れて鬱が13部品になります

どちらも KanjiVG にある画をそのまま使うだけで、組み上がりは本物と1画も違いません。

## たぐる

好きなことばから、Wikipedia 日本語版の本文の最初のリンクをたどりつづけます。
一度通った記事に戻れば「輪」、たどれるリンクがなければ「行き止まり」です。

英語版では、こうしてたどると多くの記事が Philosophy に着くことが知られています。
日本語版でどうなるかは、たぐってみるまでわかりません。

- **最初のリンク**は、本文の段落（表・囲み・図の外）にあるいちばん最初のリンク。
  括弧（　）の中・注釈・斜体・まだ書かれていない記事・記事でないページ（ファイル・カテゴリなど）は数えません
- 自分自身への転送だったリンクは飛ばして、次のリンクへ進みます
- 段落にリンクが無い記事（曖昧さ回避など）は、箇条書きから探します
- 記事は MediaWiki API（`action=parse` の冒頭の節）でその場で読みます。サーバーは要りません
- 読んだ記事は3日間 localStorage に覚えておき、同じ道は読み直しません。
  たぐった記録もこの端末に残り、「これまでに着いたところ」に輪ごとにまとまります
- `?q=ことば` で、そのことばから始まるページになります（結果の共有ボタンがこの形で作ります）

### 設定

`taguru/index.html` の先頭 `CFG` で調整できます。

| 項目 | 値 | 意味 |
|---|---|---|
| `MAX_STEPS` | 80 | ここまでたどっても終わらなければ打ち切る |
| `CANDIDATES` | 4 | 1記事から控えておくリンクの数（自分への転送などで使えないときの予備） |
| `PACE` | 480 | 新しく読みこんだ記事を出すまでの最短の間（ミリ秒） |
| `TTL` | 3日 | 読みこんだ記事を覚えておく時間 |
